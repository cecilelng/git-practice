# Git concepts

- **Working directory**: The working directory is the folder where the work is in progress. 
- **Staging area**: This is the equivalent of draft. The files are not commited, they're being worked on. 
- **Repository**: A folder to organize the work. 
- **Commit**: Action of publishing the work. 
- **Branch**: A subfolder inside the repository. 
- **Remote**: I don't know.
